Scope:
  Phase 1B analytical path kernel for explicit bend programs.
  Compiles every source straight or bend command into one exact line or
  circular-arc primitive. Adds continuous poses and cumulative stations,
  signed bend centers, source-command provenance, exact circular extrema,
  exact XY path bounds, finished-inside-edge reference length, and open/closed
  endpoint validation.

Reference-axis contract:
  The Batch 003 analytical path explicitly uses the desired finished inside
  edge. Its reported station length is an inside-reference path length. It is
  not a strap centerline length, neutral-axis developed length, or cut length.

Not included:
  No sampled point path.
  No diagnostic path or strap-solid rendering.
  No polygon or regular-polygon front end.
  No wave-pattern compiler or schedule grammar.
  No strap-specification or forming-calibration assumptions.
  No fixture geometry.
  No self-intersection or near-intersection analysis.
