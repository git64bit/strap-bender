Batch 018 implements:
  - new fixture-segmentation contract version 1;
  - new assembly-datum, printable-component, and segmentation-plan records;
  - fixture_layout_mode = auto | full_form | segmented on all four shape
    workbenches;
  - fixture_component_index selects the component rendered for STL export;
  - auto mode preserves the existing one-piece fixture when its complete base
    fits the configured print envelope;
  - auto mode enters segmentation when the one-piece base is oversized;
  - segmented mode forces component planning even when one piece would fit;
  - full_form mode preserves the prior asserting print-envelope contract;
  - global full-path fixture and clearance validation still occurs before
    segmentation, so segmentation does not hide an unsafe path interaction;
  - interior split candidates occur only strictly inside analytical straight
    primitives; no bend post or arc follower is split;
  - long individual straight primitives receive additional deterministic split
    candidates based on the configured print envelope;
  - a greedy deterministic planner chooses the farthest candidate that keeps
    each component inside the print envelope;
  - component IDs are stable and zero-padded, for example
      WAVE_PATTERN_LAB_BEND_POST_FIXTURE__C001
  - each component preserves exact global station start/end, global XY point,
    heading, source-command identity, assigned bend stations, and base bounds;
  - adjacent components share an exact station/point/heading boundary datum;
  - each bend station is assigned to exactly one component;
  - component rendering translates the selected global component to a local
    XY print origin without changing its internal geometry;
  - reporting prints the complete component manifest and global/local setup
    datums;
  - the first long-form strategy is explicitly sequential_straight_split.

Important Batch 018 boundary:
  These components are sequential station modules, not mechanically butt-jointed
  tiles. Their global base-margin coverage may overlap. Exact station and tangent
  datums are the setup authority. Physical joiners, mounting keys, datum marks,
  tiled assembly, and other long-form setup aids remain later Phase 6 work.

This batch deliberately does NOT add:
  - empirical target-to-tool radius compensation;
  - neutral-axis or strap cut-length correction;
  - a claim that nominal tool radius predicts relaxed PET radius;
  - mechanical inter-component keys or butt joints;
  - Catalog promotion;
  - forming-temperature/process recommendations.
