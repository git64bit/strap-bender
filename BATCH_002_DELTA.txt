Scope:
 Phase 1A foundation only.

 named accessors, validation, reporting, exact-name project and bend-program
 registries, arbitrary-length program routing, report-only workbenches, and
 direct-open F5 contract tests.

Correction from the first issue:
 The Bend Program workbench no longer exposes fixed Bend A, Bend B, Bend C,
 Straight A, Straight B, or Straight C Customizer fields. It selects one
 complete bend-program record by exact name. main.scad consumes the resolved
 command list without knowing or limiting its length.

 No calibration assumptions.
 No fixture geometry.
