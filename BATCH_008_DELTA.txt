Scope:
 Phase 3A named pattern blocks, compact repetition instances, and the first
 long-wave authoring route.

This batch implements native, versioned records for pattern elements, reusable
pattern blocks, parameter assignments, repetition instances, expanded-command
provenance, and derived pattern compilation. A pattern parameter accepts the
existing scalar, explicit, periodic, or every-nth numeric value sources.
Parameter values resolve once per repetition rather than once per expanded
command.

The first reusable topology is THREE_SEGMENT_S_WAVE:
 base straight -> +A bend -> rising straight -> -2A bend -> falling straight
 -> +A bend.

Every complete repetition returns to its starting heading. The three straight
families use independent parameter schedules. All three bends in one wave reuse
that wave's angle and finished-inside-radius values. Therefore the included
one-based every-nth radius schedule assigns 5 mm to all bends in waves 3, 6, 9,
and so on, while all other waves use 1.6 mm.

The Wave Pattern Customizer supports:
 - arbitrary positive wave count without per-bend controls;
 - constant, periodic, or exact per-wave arrays for base, rising, and falling
   tangent-to-tangent straight lengths;
 - one wave-angle value, with local multipliers +1, -2, +1;
 - constant, periodic, or every-nth finished inside-radius assignment by wave;
 - report-only or optional diagnostic-path execution.

The Laboratory reference instance contains 30 waves, 180 normalized commands,
90 straights, and 90 bends. Its finished-inside-edge analytical reference is
approximately 4757.61 mm, or 15.61 feet. Ten selected waves contain 30 R5 bends;
the other 20 waves contain 60 R1.6 bends. This remains an analytical reference
length, not a neutral-axis developed length or strap cutting length.

Authority and provenance:
 The named pattern block and compact pattern instance are authoritative
 authoring intent. Resolved parameter arrays and expanded bend-program commands
 are derived execution data. Every expanded command receives a contiguous
 source index plus repetition index, local element index, and stable local
 element label. Pattern expansion enters the existing bend-program,
 analytical-path, sampling, and diagnostic-rendering pipeline.

Performance boundary:
 Parameter schedules are resolved once before command expansion. The compiler
 indexes those resolved arrays directly, avoiding full schedule reconstruction
 for every local command. The 30-wave contract also samples the analytical path
 with bounded point count.

Not included:
 No arbitrary formula or callback schedule grammar.
 No additional pattern topology library beyond the first S-wave block.
 No very-high-repetition runtime benchmark or fixture segmentation planner.
 No polygon or analytical-path self-intersection diagnostic.
 No strap solid, exact ULINE strap record, forming calibration, neutral-axis cut
 length, or production fixture geometry.
