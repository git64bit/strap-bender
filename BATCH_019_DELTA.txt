Batch 019 implements:
  - new fixture setup-aid contract version 1;
  - a setup-aid source record separate from target geometry, bend-post fixture
    policy, and the derived segmentation manifest;
  - registration_mode = pin_pair | none;
  - nominal registration-pin diameter plus explicit diametral printed-hole
    clearance;
  - configurable tangent spacing and left-normal offset for the pin pair;
  - a keyed two-hole pattern derived from each exact interior component-split
    point and heading;
  - the previous component end and next component start independently derive
    numerically identical global registration-hole centers;
  - only interior component_split datums receive registration holes; path start
    and final path end are not drilled by this policy;
  - through-holes are rendered into the selected segmented component after its
    normal local-print-origin translation;
  - registration-hole validation requires each complete hole circle to remain
    inside that component base;
  - hole edges must remain clear of the complete analytical strap path by at
    least nominal strap thickness plus configured fixture clearance;
  - hole edges must also preserve the configured minimum gap from every bend
    post / conservative follower envelope;
  - component_label_mode = recessed_corner | none;
  - each segmented component receives a recessed zero-padded physical index
    mark (001, 002, ...), while the full deterministic component ID remains the
    data-model identity;
  - the mark is placed in the protected base-margin corner and has configurable
    text size and recess depth;
  - full reports include both global and local registration-hole coordinates;
  - all four fixture-capable shape workbenches expose the segmented setup-aid
    controls;
  - the complete Wave Pattern segmented route validates the setup-aid policy
    before rendering the selected component.

Important Batch 019 boundary:
  The Batch 018 components remain sequential station modules. Their global base
  coverage may overlap. Batch 019 pin pairs are transfer/common-board alignment
  datums; they do NOT convert the components into mechanically butt-jointed
  tiles and do not assert that all components can be assembled simultaneously.

Default setup-aid values:
  registration mode                 pin_pair
  nominal pin diameter              3.0 mm
  diametral printed-hole clearance  0.3 mm
  resulting hole diameter           3.3 mm
  tangent center spacing            8.0 mm
  left-normal offset                3.0 mm
  physical component mark           recessed_corner
  mark size                         2.5 mm
  mark depth                        0.4 mm

This batch deliberately does NOT add:
  - empirical target-to-tool radius compensation;
  - neutral-axis or strap cut-length correction;
  - a claim that nominal tool radius predicts relaxed PET radius;
  - male/female inter-component keys or a butt-jointed tile strategy;
  - a common setup board or rail model;
  - Catalog promotion;
  - forming-temperature/process recommendations.
