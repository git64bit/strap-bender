Scope:

Development priority:
  Application completion remains primary. Pending coupon measurements,
  springback fitting, neutral-axis calibration, and empirical PET cut correction
  do not block this batch.

Batch 023 implements:
  - one continuous 3D strap-body preview using the selected strap material's
    nominal width and nominal thickness;
  - the existing bounded sampled analytical path as display geometry only;
  - strap width along Z and strap thickness in the XY bend plane, matching the
    existing standing-on-edge fixture convention;
  - square open-path ends and filled sampled interior joints;
  - open and closed path support;
  - Bend Program, Vertex Polygon, Regular Polygon, and Wave Pattern routing;
  - an independent Show strap solid workbench flag;
  - coexistence with the thin diagnostic path and with bend-post fixtures;
  - automatic Z placement on top of the fixture base when fixture rendering is
    active;
  - segmented-fixture alignment by clipping the global strap display to the
    selected component base bounds and applying the same local XY translation;
  - strap-material routing whenever strap-solid display is enabled;
  - a strap_solid-only render mode when no diagnostic path or fixture is shown;
  - explicit validation and reporting before geometry dispatch;
  - direct-open open/closed geometry and workbench-routing contract tests.

Important geometry boundary:
  The authoritative analytical axis remains named finished_inside_edge. Across
  alternating left/right bends that reference does not identify one globally
  consistent physical material face along every intervening straight. Batch 023
  therefore centers nominal strap thickness on the analytical reference for one
  continuous visualization rule. This is display-only. It does NOT redefine:
    - requested finished bend radius;
    - analytical line/arc geometry;
    - nominal cut length;
    - neutral-axis position;
    - fixture post locations;
    - follower clearance;
    - target-to-tool compensation.

This batch deliberately does NOT add:
  - empirical springback compensation;
  - calibrated neutral-axis/K-factor fitting;
  - empirical cut-length correction;
  - a new fixture family;
  - physical Catalog acceptance;
  - manufacturing semantics derived from the strap-solid mesh.
