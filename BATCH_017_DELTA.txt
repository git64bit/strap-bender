Correction 1 — fixture material dependency routing:
  User-visible failure:
    Expected exactly one strap material named 'ULINE_S_1655_BLACK'; found 0.
  Reproduced through both vertex_polygon and bend_program fixture routes.
  Root cause:
    config/materials.scad exposed the material registry by workbench name, but
    the shape-authoring workbenches were not listed even though
    bend_post_fixture planning requires the material registry.
  Correction:
    Any workbench entering render_mode = "bend_post_fixture" receives the
    Laboratory strap-material registry. The dependency is therefore keyed to
    the physical fixture route rather than duplicated across shape front ends.
    calibration_evidence is also explicitly material-enabled for future
    persisted physical trials.

Correction 2 — non-fatal Radius Observation completeness gate:
  User-visible failure:
    Setting Observation ready = true with the default incomplete worksheet
    immediately asserted on the empty specimen ID.
  Root cause:
    readiness directly entered strict evidence validation before checking
    whether all required worksheet fields had been supplied.
  Correction:
    - a radius-observation completeness function returns all missing/invalid
      worksheet issues without assertions;
    - a transient calibration-trial record is emitted only when the issue list
      is empty;
    - incomplete ready state reports every issue and emits no evidence record;
    - strict validate_radius_observation() and validate_calibration_trial()
      remain unchanged and still run for a complete ready observation;
    - physical-evidence semantics are therefore not weakened.
